A modern, high-performance, and responsive promotional website built for **Happy Packers & Movers and Logistics**, a premier house shifting and commercial relocation service provider based in Coimbatore, Tamil Nadu.

## Features

* **Multi-Page Layout:** Fully structured HTML pages for Home, About Us, Services, and Contact details.
* **Instant WhatsApp Booking:** Integrated one-click WhatsApp action triggers for instant quote inquiries and customer support.
* **Responsive Design:** Optimized layout ensuring smooth performance across mobile devices, tablets, and desktop displays.
* **SEO & Local Business Markup:** Configured with meta tags and JSON-LD structured data for regional search optimization in Coimbatore and across India.
* **Automated CI/CD:** Configured with GitHub Actions for automated W3C HTML/CSS code validation and deployment to GitHub Pages.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling & Assets:** WebP compressed graphics, custom responsive breakpoints
* **Version Control:** Git & GitHub (Branching & PR workflow)
* **Hosting & CI/CD:** GitHub Pages, GitHub Actions workflows (`.github/workflows/`)
